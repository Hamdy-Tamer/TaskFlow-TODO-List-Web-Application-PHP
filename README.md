## ✨ Features

### 📝 Task Management
- **Create Tasks** — Add new tasks with titles and optional descriptions
- **Edit Tasks** — Modify existing tasks with a dedicated edit interface
- **Delete Tasks** — Remove individual tasks with confirmation prompts
- **Clear All Tasks** — Bulk delete all tasks in one click with safety confirmation
- **Toggle Status** — Mark tasks as complete or pending with a single click

### 📊 Dashboard Statistics
- **Total Tasks Counter** — View the total number of tasks at a glance
- **Pending Tasks Counter** — Track tasks that still need attention
- **Completed Tasks Counter** — Monitor your progress with completed task count
- **Real-time Updates** — Statistics update instantly after each action

### 🎨 Professional Interface
- **Dark Theme** — Elegant dark mode design for reduced eye strain
- **Gradient Accents** — Beautiful gradient colors for visual hierarchy
- **Smooth Animations** — Polished transitions and hover effects
- **Responsive Design** — Fully responsive layout for all screen sizes
- **Status Badges** — Visual indicators for task completion status
- **Icon Integration** — Rich Font Awesome icons throughout the interface

### ⚡ User Experience
- **Form Validation** — Error messages with animated icons when title is empty
- **Sticky Header** — Header remains visible while scrolling through tasks
- **Custom Scrollbar** — Styled scrollbar matching the dark theme
- **Empty State** — Friendly placeholder when no tasks exist
- **Task Metadata** — Display creation dates and times for each task
